# Starter kits

A starter kit is a whole PocketOne app to begin from: a `pb_pages` folder (and sometimes migrations), written in
TypeScript with [ETS templates](/docs/extensions/pages/ets), run by the stock `pocketone` binary with no build step.
Start an app from one, then run it:

```bash
pocketone pages create myapp --starter <kit>
cd myapp
pocketone superuser upsert you@example.com <password> --dir ./pb_data
pocketone serve --dir ./pb_data
```

`pocketone pages create myapp` with no `--starter` uses **minimal**, and `pocketone pages starters` lists the kits. The
folder must not exist yet.

| [ask](/docs/starters/ask) | Ask your docs a question and get a short answer with links to the pages it came from. |

| [daisyui](/docs/starters/daisyui) | A layout with a responsive navbar and drawer, built with [Tailwind CSS](https://tailwindcss.com/) and [DaisyUI](https://daisyui.com/) (cupcake theme). |
| [daisyui-docs](/docs/starters/daisyui-docs) | A docs site built from Markdown pages, styled with [Tailwind CSS](https://tailwindcss.com/) and [DaisyUI](https://daisyui.com/). |
| [datastar](/docs/starters/datastar) | A realtime chat with rooms and a live counter, built with [Datastar](https://data-star.dev/) and the Datastar add-on (`_private/datastar.js`, listed as `'datastar'`) and the built-in `realtime` plugin. |
| [htmx](/docs/starters/htmx) | A realtime demo with [htmx](https://htmx.org/) and the built-in `realtime` plugin. |
| [minimal](/docs/starters/minimal) | A single `index.ets` page: a Tailwind (CDN) splash screen with no layout, no config and no build step. |
| [mvp](/docs/starters/mvp) | One page styled with [MVP.css](https://andybrewer.github.io/mvp/): classless CSS that makes plain semantic HTML look good, for a minimal, responsive, mobile-friendly site with no build step. |
| [tsx](/docs/starters/tsx) | Server-rendered components: a `+layout.tsx`, an `index.tsx` page built from a `_private/Feature.tsx` component, and `index.ts` beside it, which loads the page's data. |

Everything in the [Pages docs](/docs/extensions/pages) applies to an app made from a kit; each kit's page lists its
files and what each one does.
